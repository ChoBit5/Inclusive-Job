# Inclusive-Job

# Nombre del producto: Inclusive job
# Descripción

InclusiJob IA es una plataforma web inclusiva que busca conectar a personas con discapacidad con empresas y reclutadores mediante herramientas de accesibilidad e inteligencia artificial. El sistema permitirá crear perfiles profesionales, subir currículums y certificaciones, publicar vacantes y relacionar las habilidades y necesidades de los postulantes con oportunidades laborales compatibles.

# Objetivo
Desarrollar una plataforma web accesible, segura e inclusiva que facilite la búsqueda y contratación de empleo para personas con discapacidad, utilizando inteligencia artificial para mejorar la compatibilidad entre candidatos y vacantes y reducir las barreras presentes en los procesos de reclutamiento tradicionales.
